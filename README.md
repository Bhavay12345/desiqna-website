# DesiQna Interview Experiences Page

A frontend web application designed to present interview experiences from different companies in a clean and structured manner, improving user experience and accessibility.

##  Features
- Organized interview experiences
- Clean and responsive UI
- Easy navigation
- DSA Roadmap and resources section

##  Tech Stack
- HTML
- CSS
- Bootstrap
- JavaScript

##  Purpose
The goal of this project is to help students easily access and understand interview experiences of various companies in one place.
